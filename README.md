# GameBoy Android

Мобільний ігровий застосунок-емулятор ретро-консолі Game Boy для Android.

## Ігри
- Змійка (Snake)
- Арканоїд (Arkanoid)  
- Space Shooter

## Особливості
- Інтерфейс у стилі Nintendo Game Boy
- Три кольорових стилі (White / Black / Classic)
- Повноекранний режим з жестовим керуванням
- Локальна база даних рекордів (Room SQLite)

## Встановлення
[Завантажити APK](https://github.com/DenchikBrenchick/gameboy-android/releases/latest)

## Технології
- Kotlin · Android SDK · Canvas API · Room (SQLite)
